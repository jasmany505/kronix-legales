# Kronix — Página legal

Proyecto estático listo para GitHub y Vercel.

## Estructura
- `index.html` — página principal
- `style.css` — estilos
- `assets/` — carpeta para imágenes

## Vercel
Importa el repositorio desde GitHub.
- Framework Preset: Other
- Build Command: vacío
- Output Directory: vacío

`index.html` está en la raíz para evitar errores 404.

## Imágenes
El documento original contiene rutas locales de Windows (`file:///C:/...`), que no funcionan en GitHub/Vercel. Las imágenes deben colocarse en `assets/` si se quieren publicar.

## Imágenes

Las tres imágenes están incluidas en `assets/` y se muestran desde `index.html`:

- `assets/wps1.png`
- `assets/wps2.png`
- `assets/wps3.png`
